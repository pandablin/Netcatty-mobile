## 细节打磨

- **修复列表视图长按出现方形阴影**：按下时的高亮现在跟着卡片的圆角走，不会再超出卡片。实现上用的是高亮自带的形状，没有额外的裁剪层，渲染更省。
- **按压反馈改成 iOS 风格**：全局去掉了 Android 式的水波纹（网格视图里长按时出现的那个灰圆圈），按下时只有一层很淡的底色，和 Claude App 一样。
- **页面切换动画**统一为 iOS 的左右滑动。

## 性能

- 切到其他标签页时，后台页面里的动画会自动暂停（终端光标闪烁、加载圈、进度动画等），不再在后台占用渲染帧，页面状态照常保留。
- 去掉水波纹后，每次点按也少了一段动画。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.9.3-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

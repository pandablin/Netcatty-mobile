## 改进

- **快捷键栏可以一键添加 Ctrl+C**：点终端工具栏的「编辑快捷键」（调节图标），在「点击添加内置按键」里点 Ctrl+C 即可加入。Ctrl+D、Ctrl+Z、|、/、~ 也可以这样加。
  - 内置按键现在也能移除，用不到的 Home、End 等可以去掉。
  - 共 13–14 个按键时自动排成每行 7 个，加上 Ctrl+C 仍然是两行。
- **灵动岛**：
  - 收起时系统图标右下角的绿点不再被裁掉一半；
  - 展开后右上角的会话数改为图标加数字，不再显示成「2 个…」。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.8.2-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

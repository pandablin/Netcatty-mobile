## 改进

- **默认快捷键栏加入 Ctrl+C**，仍然保持两行，方向键还是十字形：
  - 第一行：Esc、Alt、**Ctrl+C**、↑、**|**、粘贴
  - 第二行：Tab、Ctrl、←、↓、→、Shift
  - 不常用的 Home、End 去掉了（命令行里可以用 Ctrl+A / Ctrl+E 代替）。
  - 没改过快捷键顺序的话，更新后会自动换成新布局；改过的会保留你自己的设置。
- **编辑快捷键更灵活**：点工具栏的「编辑快捷键」（调节图标），在「点击添加内置按键」里一点就能加入 Home、End、Ctrl+D、Ctrl+Z、/、~ 等。
  - 内置按键现在也能移除。
  - 共 13–14 个按键时自动排成每行 7 个，仍然是两行。
- **灵动岛**：
  - 收起时系统图标右下角的绿点不再被裁掉一半；
  - 展开后右上角的会话数改为图标加数字，不再显示成「2 个…」。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.8.2-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

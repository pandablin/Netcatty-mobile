## 界面

- **系统图标去掉彩色边框**：Ubuntu、Debian、Linux 等图标不再套橙色 / 红色 / 黄色的底框和描边，改为很浅的中性底色，列表更干净。
- **主机详情弹窗**：系统图标不再被拉伸成一整条彩色长条，按原尺寸居中显示。
- **连接成功不再弹「已连接」提示**：它会在终端底部停留约 4 秒，挡住终端工具栏；连接状态已经能从标签页和主机列表上的绿点看到。

## 修复

- **连接后识别系统不再触发云同步**：之前每次 SSH 连接都会把主机标记为「已修改」，自动同步随即上传一次，这会让同步文件不断变大（桌面端 1.1.83 修过同样的问题）。现在系统信息只保存在本机，内容没变时不写入。
- **连接后的系统信息写入不再覆盖刚保存的主机修改**。
- **修复切换标签页时整个页面可能被重建**：在只对部分页面启用自定义背景时，切换标签页会让所有页面（包括终端）被重新创建。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.6.1-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

## 图标

- **修复 iOS 桌面图标的黑框**：原图标自带圆角、描边和透明边距，iOS 不允许图标透明，会把透明部分填成黑色。现改为满版不透明图标，由系统裁切圆角。

## 界面

- 网格视图卡片更紧凑，去掉图标和名称之间的大片空白。
- 已连接的主机在图标右下角显示绿色圆点（网格 / 列表 / 树形视图都有）。
- 视图切换菜单中当前视图显示勾选标记。
- 树形视图「未分组」改用普通文件夹图标，不再是带斜杠的「禁用」样式。

## 性能

- **同步加解密移到后台线程**：PBKDF2（60 万次）、AES-GCM 和 JSON 解析不再阻塞界面，同步时不会卡住。
- **缓存派生密钥**：同一次同步里对同一文件的多次解密（合并、上传后校验、未变化时的定期检查）只做一次 PBKDF2。
- **Gist 增量检查**：定期检查使用 ETag（If-None-Match），云端未变化时 GitHub 返回 304，不再重复下载整个保险库，省流量也省电。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.6.0-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。新图标可能需要重启手机后才会刷新。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

本 Fork 的阶段性正式版，包含 1.5.0 以来的全部修复与优化，并新增以下改动。

## 本版新增

- **修复 iOS 输入时候选词栏闪烁**：终端用来接收键盘输入的隐藏输入框，之前每输入一个字符都会被整体重置，iOS 键盘（尤其是第三方输入法）会随之刷新候选词栏，看起来一直在闪。现在只在必要时重置，打字时候选栏保持稳定；拼音输入只在上屏后发送，不会多发退格。
- **深色模式下系统图标看不清**：大部分 logo 是纯黑线条，在深色背景上几乎看不见。深色模式下统一显示为浅色单色，浅色模式保持原样。
- **启动不再白闪**：启动屏背景跟随系统深浅色，深色模式下打开 App 不再先闪一屏白色。
- README 下载与 CI 链接指向本仓库，并列出本 Fork 的改动。

## 自 1.5.0 起的主要改进

- 连接：修复 Android 连接瞬间失败时闪退；IPv6 与代理握手修正。
- 私钥：加密私钥弹窗输入口令，可保存到钥匙串；解密在后台进行。
- 终端：可设置点击终端是否弹出键盘，翻看历史时不跳回底部；中文分包乱码修复；Telnet 协商修正；去掉连接成功提示对工具栏的遮挡。
- 保险库：首次打开与保存不再卡顿；修复重复弹窗与修改被覆盖；已连接主机状态点；系统图标去掉彩色边框。
- 同步：加解密移到后台线程并缓存派生密钥；Gist 增量检查（ETag）；修正大小判断；SSH 连接不再触发同步上传。
- 其他：iOS 图标去黑框；性能监控按需采样；CI 自动发布 Release。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.7.0-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

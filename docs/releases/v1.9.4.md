# v1.9.4：命令分组、同步提示与安全加固

本次源码版本为 **1.9.4+46**，基于 v1.9.3 的 `f7ea0e8`。发布附件中的本地 Android 测试构建显示名称为 **Netcatty**，采用独立包名，安装信息见下文。

## 命令片段分组

- 手机命令列表按桌面已有的 `snippet.package` 和 `snippetPackages` 分组，默认收起，显示各组数量；没有分组的片段归入“未分组”。
- 编辑片段时可输入新分组或选择已有分组，保留桌面兼容字段及空分组。
- tmux 的片段选择也使用分组列表；选择只填入命令，展开分组不会执行命令。
- 补齐英文文案，并修正本地化覆盖测试对空字符串、转义引号及同一行多个字符串的误判。

## 同步提示与桌面兼容

**现场“同步成功但没有内容”的原因已确认为 WebDAV 地址指向空目录；修正目录后，原版即可同步。这次发布不将该配置问题描述为解密或保存故障。**

- 云端找不到 `netcatty-vault.json` 且手机也没有数据时，明确提示检查同步目录，不再创建空保险库并笼统提示成功；有本地数据时仍支持首次上传。
- 同步结果显示云端读取及手机现有的主机、脚本和密钥数量，便于确认同步内容。
- 补齐桌面 Netcatty **1.1.90** 的 `monitorPanels`、`browserBookmarks` 集合兼容，覆盖合并、删除、比较和缩量保护。使用桌面代码生成的合成加密样本验证 WebDAV 读取、保存及重新打开后的恢复，不使用个人保险库作为测试数据。

## 安全加固

- 按 [xterm2 5.5.0 的安全变更](https://pub.dev/packages/xterm2/changelog#550---2026-11-20) 最小移植，默认不再回应远端 OSC 52 系统剪贴板读取请求。**用户手动复制、手动粘贴仍可用**，远端主动复制到剪贴板及已有输入法兼容行为保持。
- 在解密前校验 PBKDF2 工作因子、salt/IV 长度和截断数据，避免恶意同步包指定无限工作量。正常写入仍为 600,000 次；读取上限 2,000,000 次是本客户端的资源保护策略，不是协议官方上限。
- WebDAV、Gist、S3 响应改为流式限长，超限停止读取；普通保险库默认 32 MB，Gist 元数据另限 64 MB，不仅依赖 `Content-Length`。
- SFTP 列表和递归传输拒绝带目录跳转或路径分隔符的伪造文件名，防止把远端文件名当作目标路径。
- 更新并校验 Gradle wrapper，固定分发 ZIP 的 SHA-256。

审查未发现确定的刻意后门证据；这不代表绝对安全，也不是发布 APK 与全部源码等价的证明。范围及剩余边界见 [安全审查记录](../SECURITY_REVIEW_2026-11-23.md) 和附件报告。

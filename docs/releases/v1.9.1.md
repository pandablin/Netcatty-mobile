## 性能优先

1.9.0 的新界面在部分操作时会一顿一顿的。我分析了你的录屏，找出原因并做了这些修复：

- **切换深色 / 浅色、换主题不再卡顿**：
  - 原来切换时有一段 0.2 秒的渐变动画，这期间每一帧都要重新构建所有页面（包括打开着的终端），录屏里能看到明显停顿。现在改为瞬间切换。
  - 主题配色改成只计算一次并缓存。原来随便改一个设置开关，都要重新算两套主题配色。
  - App 外层现在只在主题、语言变化时才重建，改其它设置不会再牵动整个界面。
- **主机列表滚动更顺**：
  - 系统图标从 SVG 改成预先渲染好的 PNG。原来每个图标在滚动的每一帧都要重新绘制，深色模式下还要额外走一层离屏渲染；现在只绘制一张图片。
  - 去掉了主机卡片的按压缩放动画。手指一碰开始滑动，卡片就会缩一下，滑动时看起来像在抖。
- **底部标签栏不再做实时毛玻璃模糊**，改成 95% 不透明，阴影也减轻了。原来列表滚动时，标签栏后面的模糊每一帧都要重新计算。外观基本不变，悬浮胶囊和会滑动的选中块都保留。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.9.1-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

## 改进

- **主机列表更紧凑**，服务器多时少滑很多：
  - 网格卡片高度从 136 降到约 96，卡片间距也缩小了；
  - 列表和分组视图的行高、间距都缩小了，图标也略小。
  - 系统字体调大时，卡片会跟着变高，文字不会被截断。
- **可以调整服务器顺序**：点右上角的视图按钮，菜单里新增：
  - 按名称排序（默认，置顶的主机在最前）
  - 按最近连接排序
  - 自定义顺序
  - 「调整顺序…」：按住每行右侧的手柄拖动，点「保存顺序」后自动切到自定义顺序。新加的服务器排在最后。
- 顺序只保存在这台设备上，不会改动云同步或桌面端里的服务器数据。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.8.3-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

# Netcatty 1.10.0：同步上游并保留定制

合入 wxte/Netcatty-mobile 的 4 个新提交，最新上游提交为 [83adbdf](https://github.com/wxte/Netcatty-mobile/commit/83adbdffd68ce12b5e2326ae69a14c59acc3c9cc)。本仓库源码版本为 **1.10.0+48**，在上游 1.10.0 的基础上保留 pandablin 分支已有功能。

## 上游新功能与打磨

- **设置页改成 iOS 分组样式**（参照 Claude App）：
  - 首页顶部是 Netcatty 卡片和版本号，下面分为「通用」「数据」「Catty Agent」「关于」几组，每行一个图标，右侧显示当前值和箭头；
  - 点进去是「外观」「终端与连接」「灵动岛」「语言」「云同步」「安全与隐私」等子页面，支持 iOS 从左边缘右滑返回；
  - 外观设置（深浅色、主题、背景、字号、语言等）改为即改即生效，去掉了「保存外观设置」按钮。
- **长按主机弹出 iOS 风格菜单**：背景模糊，主机卡片浮起，下面是「连接」「复制 IP」「查看详情」「编辑」「删除」（红色）。列表、网格、树形三种视图都支持；原来的详情框在「查看详情」里。
- **点灵动岛或锁屏上的实时活动，直接打开对应服务器的终端**（原来只是打开 App）。

## 细节

- **启动画面底色与 App 一致**：浅色 #F9F9F7、深色 #151515，冷启动不再从纯白或纯黑闪一下。
- **性能**：改主机排序、灵动岛开关这类与终端无关的设置时，终端页不再跟着重建。

## 保留的定制内容

- **自有 GitHub OAuth 应用**：继续使用构建时配置的公开 Client ID，不恢复第三方默认值；GitHub 授权范围仍为 `gist read:user`。仓库构建变量继续使用 `NETCATTY_GITHUB_OAUTH_CLIENT_ID`。
- **命令分组**：保留桌面端 `package` / `snippetPackages` 分组，手机端按组折叠显示，保留空分组、未分组命令和编辑元数据。
- **同步兼容性**：保留桌面端监控面板、浏览器书签及其删除信息；空云目录与空本机不会被当作已有内容同步成功。
- **已有安全修复**：保留终端剪贴板读取限制、加密参数和 HTTP 响应大小校验、SFTP 文件名检查，以及已核验的 Gradle Wrapper。

## 安卓测试包安装

本分支额外修复两处 Android 兼容问题：设置子页的系统返回键会先回到设置首页，隐藏设置页不干扰终端返回；横屏和短屏上的主机长按菜单可以滚动，全部操作均可触达。

下载 [Netcatty 1.10.0 ARM64 APK](https://github.com/pandablin/Netcatty-mobile/releases/download/v1.10.0/Netcatty-1.10.0-android-arm64.apk)。名称仍为 **Netcatty**，沿用本仓库上一版测试包的包名 `app.netcatty.mobile.audit` 和签名，版本号递增，可覆盖安装此前提供的 1.9.5 测试版并保留应用数据，无需卸载。

本包与 wxte 原版的安装身份不同，不能直接覆盖原版。iOS 相关上游源码已合入，本次没有构建或验证 iOS 安装包。

构建清单、签名记录和 SHA-256 摘要随本次 Release 提供。实际手机上的安装、登录及同步不在本地自动化测试的验证范围内。

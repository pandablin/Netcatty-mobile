## 新功能

- **灵动岛 / 锁屏实时活动**（iOS 16.2+，参考 Termius）：连上服务器后切到后台，灵动岛会显示当前服务器。
  - 收起时：左边是系统图标（绿色＝已连接，橙色＝正在重连，灰色＝App 已被系统结束、状态未更新），右边是服务器名；同时开着多个会话时会附上会话数。
  - 长按展开或在锁屏上：服务器名和 `用户@地址`、已连接时长（系统自动计时）、最近执行的命令（最多两行），多个会话时下方列出每台服务器的图标。
  - 最近命令是在按回车时从提示符那一行读取的，所以 Tab 补全和上下键调出的历史命令也能正确显示；vim、htop 等全屏程序里按回车不会记录。
  - 关闭所有会话后自动消失。
- 设置里新增两个开关：「灵动岛显示连接」和「灵动岛显示最近命令」（命令里有密码时建议关掉后者）。

## 注意

- 灵动岛内容是系统按快照渲染的，不能做成滚动字幕；只有连接时长会自己走。
- 这一版新增了一个小组件扩展（`NetcattyWidgets.appex`）。用 Sideloadly 签名时，免费 Apple ID 会多占用一个 App ID（每 7 天最多 10 个）。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.8.0-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。灵动岛功能仅限 iOS。

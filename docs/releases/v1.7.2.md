## 新增

- **设置 → 终端 →「显示输入法联想词（实验）」**，默认关闭。
  - **关闭（默认）**：和原版一样，每个按键后清空输入框，输入一定准确，但第三方输入法的候选栏会跟着闪，也没有联想词。
  - **开启**：输入框保留正在输入的词，候选栏稳定不闪，可以显示联想词。选中联想词或输入法整词替换时，会按差异发送退格和新内容，终端上显示的和输入框一致。只在两种情况下清空输入框：删除到行首之后，以及按回车提交一行之后。同时输入框不再标记为邮箱类型，输入法不会再给出 `@qq.com` 这类补全。

  这是针对 1.7.0「删除键发送联想词」问题的修正版：那次的原因是输入框在输入到一半时被清空，而第三方输入法自己还保留着这个词，于是按删除时把整个词重新发了一遍。开启后如果仍发现按键或删除后发出了没输入的内容，请关闭此项并告诉我。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.7.2-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

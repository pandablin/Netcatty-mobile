## 改进

- **首次连接时终端不再抖动**：键盘弹出动画期间，终端可用高度几乎每一帧都在变化，终端随之反复重新排版、滚动，并把新的窗口大小发给服务器（bash 会重绘当前行），看起来就是文字上下跳几下。现在等高度稳定后（约 0.14 秒）才调整一次终端大小。
- **「显示输入法联想词」改为默认开启**：已在 iOS 第三方输入法上确认，开启后候选栏稳定、可以选词，删除键行为正常。关闭后恢复原版行为：每个按键都会清空输入框，候选栏会闪、无法选词。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.7.3-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

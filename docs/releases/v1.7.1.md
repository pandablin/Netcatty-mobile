## 修复

- **按删除键会把联想词发送到终端**（1.7.0 引入，已回退）：1.7.0 为了减少候选栏闪烁，让隐藏输入框保留了正在输入的整个词，输入法因此会对这个词做整词替换，按删除键时把第一个联想词发了出去，再按又删掉。这可能向服务器发送并不是你输入的内容，因此已完整回退为原版 xterm2 的处理方式：每个按键后清空输入框，输入法没有可以替换的词。代价是第三方输入法的候选栏在打字时仍会刷新闪动；需要完全避免时，可在设置中开启「系统安全键盘」。
- **打开 App 时闪一下灰色**：App 启动的第一帧使用默认的深色主题，读取设置后才切到你选的主题，切换动画在浅色模式下表现为一层灰色闪过。现在第一帧就直接使用已保存的主题。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.7.1-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

基于 [kmh1145/Netcatty-mobile](https://github.com/kmh1145/Netcatty-mobile) 1.4.9 的修复与优化版本。

## 修复

- **连接瞬间失败时 Android 闪退**（上游 #38 #40）：纯 IPv4 网络连接 IPv6 主机、本地代理拒绝连接时，不再因保活前台服务被过早停止而闪退。
- **IPv6 与代理**：主机名可带方括号（`[2001:db8::1]`）；HTTP 代理 CONNECT 正确为 IPv6 加方括号；SOCKS5 对 IP 地址使用正确的地址类型。
- **加密私钥无法连接**（上游 #41）：口令未保存或错误时弹窗输入，可选保存到系统钥匙串（连接成功后才保存）；本次运行内重连无需重复输入；解密在后台进行，不再卡住界面；PKCS#8 / PuTTY 等不支持的格式给出转换提示。
- **主机编辑**（上游 #38）：首次打开不再卡顿（钥匙串批量读取）；快速点两下不再弹出两个窗口；保存只写入有变化的密钥；连接后写入的连接时间不再把刚保存的修改覆盖回去。

## 改进

- **终端键盘**（上游 #36）：新增设置「点击终端弹出键盘」；向上翻看历史时点击终端不会弹出键盘或跳回底部；工具栏右下角按钮改为弹出 / 收起键盘切换。
- **中文乱码**：终端输出按数据流解码，中文、emoji、制表符被拆到两个数据包时不再显示为 �。
- **Telnet**：协议命令跨数据包正确解析，不再回应 DONT/WONT。
- **性能监控省电省流量**：只在打开面板时每 3 秒采样，未查看时 15 秒一次，App 进入后台时暂停。
- 应用内更新检查改为检查本仓库的正式版。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.5.0-ios-unsigned.ipa`，用 AltStore、SideStore 或 Sideloadly 以自己的 Apple ID 重签后安装。
- **Android**：现代手机下载 `-android-arm64-v8a.apk`，不确定架构时下载通用包 `-android.apk`。
  本仓库暂未配置固定签名密钥，APK 使用调试签名：不能覆盖安装上游版本，也不能覆盖安装本仓库之后的版本，需要先卸载（卸载会清除本机数据，请先导出或开启云同步）。

## 改进

- **主机列表操作改为 Termius 方式**：点一下主机直接连接，长按弹出主机详情。
  - 一秒内连点两次只会开一个会话。
  - 列表、网格、分组三种视图都已改好。
- **主机详情新增「复制 IP」按钮**，在「编辑」左边，点一下就把主机地址复制到剪贴板。
- 设置里新增开关「点击主机直接连接」（默认开启）。关掉后恢复原来的方式：点击先显示详情。
- 右侧的 ⋯ 按钮仍然是打开编辑。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.8.1-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

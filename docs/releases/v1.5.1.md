## 修复

- **GitHub Gist 同步提示「云端保险库超过 8 MB 限制」**：之前把整个 Gist API 响应都算进了大小限制，其中包括每次同步都会增加的修订历史和 Gist 里的其他文件，即使保险库本身很小也会超限。现在只计算 `netcatty-vault.json` 本身。
- 保险库大小上限由 8 MB 提高到 32 MB（WebDAV / S3）。Gist 受 GitHub 限制，单个文件超过 10 MB 无法通过 API 读取，此时会提示改用 WebDAV 或 S3。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.5.1-ios-unsigned.ipa`，用 Sideloadly 以**与之前相同的 Apple ID 和 Bundle ID** 重新签名覆盖安装，已保存的密码和密钥会保留。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

## 界面：Claude 风格

参照 Claude App 的浅色和深色界面重新调整了外观。

- **配色**：
  - 浅色是暖调米白底（#F9F9F7）配白色卡片，深色是近黑底（#151515）配 #20201F 卡片；
  - 强调色是 Claude 的陶土橙。
- **组件**：
  - 卡片去掉了描边，圆角更大，像 iOS 的分组列表；
  - 主按钮改成黑色（深色模式下为白色）胶囊按钮，和 Claude 的「新建会话」一样；
  - 页面标题居中，开关改成 iOS 风格；
  - 输入框没有边框，只有浅灰底。
- **字体**：
  - 界面英文和数字用 DM Sans，和 Claude 界面用的 Styrene 风格相近；
  - 保险库标题「Netcatty」用衬线体 Lora，类似 Claude 的标题字；
  - 中文仍是系统苹方，终端仍是等宽字体。
  - Claude 自己的字体是商业字体，不能打包进 App，所以用这两款开源字体（SIL OFL 许可）代替，只带了拉丁字符，一共约 300 KB。
- **主题精简为 8 套**：Claude（默认）、GitHub、One、Tokyo Night、Catppuccin、Dracula、Nord、Gruvbox，每套都有浅色和深色版本。
  - **终端配色跟随主题**：每套主题都有自己的 16 色终端调色板。浅色主题下黄色、白色等不会再看不清。
  - 主题选择页直接预览每套主题的终端颜色。
  - 原来选的主题如果被移除了，会自动换成 Claude 主题。

## 性能（来自 1.9.1，未单独发布）

- 切换深色 / 浅色、换主题时去掉了 0.2 秒的全局渐变动画，改为瞬间切换，不再卡顿。
- 主题配色只计算一次并缓存；App 外层只在主题、语言变化时才重建，改其它设置不会牵动整个界面。
- 主机列表的系统图标从 SVG 改成预先渲染好的 PNG，滚动时不再逐帧重绘；去掉了卡片的按压缩放，开始滑动时卡片不再抖一下。
- 底部标签栏不再做实时毛玻璃模糊，改成接近不透明的悬浮胶囊。

## 安装

- **iOS**：下载 `netcatty-mobile-v1.9.2-ios-unsigned.ipa`，用 Sideloadly 以与之前相同的 Apple ID 和 Bundle ID 重新签名覆盖安装。
- **Android**：APK 使用调试签名，可能无法覆盖安装旧版本。

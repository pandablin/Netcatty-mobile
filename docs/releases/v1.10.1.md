# Netcatty 1.10.1：自有更新源与自动安卓发布

源码版本为 **1.10.1+49**，ARM64 APK 的 Android versionCode 为 **2049**。

## 手机端更新入口

- 检查更新、版本详情及下载跳转统一使用 `pandablin/Netcatty-mobile`。
- 识别本仓库的正式版和预发布版本，按语义版本选择最新有效版本。
- 拒绝其他仓库、非 HTTPS 或带额外认证信息的更新链接；异常返回只回到本仓库 Releases。
- 限制更新响应大小。保留原作者、许可证和历史来源记录；自动同步的上游来源仍为 wxte 仓库。

旧 APK 内的更新地址无法远程替换，因此这一次需要从本仓库 Release 下载新 APK 覆盖安装。安装 1.10.1 后，更新按钮会进入本仓库。

## 自动同步与发布

- GitHub Actions 每 6 小时检查一次上游 `main`，也可手动运行 `Sync upstream`。
- 普通变更进行三方合并，保留本地定制；真实冲突、依赖或受保护发布文件变化会停止，不覆盖本地代码。
- 有变化时先准备独立候选分支；在不含签名 Secrets 的任务中运行测试，再在独立任务中构建和校验 APK。
- 校验包名、原签名、递增版本、ARM64、OAuth 和本仓库更新地址，通过后才以非强制推送更新 `main`，并发布本仓库的 Release。
- 检查 `main` 是否在构建期间被其他修改推进，避免覆盖新提交。没有上游变化时不重复发版。

详见 [自动同步说明](https://github.com/pandablin/Netcatty-mobile/blob/v1.10.1/docs/UPSTREAM_SYNC.md)。测试和定制保护不能替代对未来上游代码的全面安全审计。

## 安装兼容

应用仍显示 **Netcatty**，包名保持 `app.netcatty.mobile.audit`，沿用之前测试包的签名，可以覆盖此前提供的测试版，无需卸载。签名材料按仓库所有者授权，经 GitHub 公钥加密后保存在本仓库的 Actions Secrets，未提交到源码或安装包。

本版本继续保留自有 GitHub OAuth、命令分组、同步兼容性、安全修复、安卓返回键及横屏菜单修复。自动发布以 Android 为主，不等待 iOS 构建。

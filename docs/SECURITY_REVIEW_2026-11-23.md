# Android 审查与修复记录（2026-11-23）

基线是 `pandablin/Netcatty-mobile` 的 `f7ea0e825ef75a531313999e883b30fba61b2a6f`。
GitHub 发布元数据将 wxte 的 v1.9.3 关联到同一提交。本次修复版本为 **1.9.4+46**。

## 审查结论

审查覆盖 Dart 网络、SSH/终端、同步、密钥存储、AI 与更新数据流，Android/iOS 原生桥接、权限及构建配置；还将 vendored xterm2 与官方发布包核验，并检查选定原生插件的来源、摘要和权限。未发现确定的刻意后门证据：没有定位到隐藏的凭据收集端点、控制服务器、远程代码自动下载执行或 AI 回复自动执行。

这不是“绝对没有后门”的保证，也不是对全部依赖逐行审计。GitHub 资产摘要、签名及权限核验不能证明第三方 APK 与源码完全等价。本次没有接入真实 WebDAV/SSH 账户，没有读取个人保险库或剪贴板，也没有运行用户的命令片段。回归仅使用虚构数据。

## 已修复的安全问题

1. **远端读取系统剪贴板**：旧版 TerminalView 会默认回应远端 OSC 52 查询，剪贴板内容会回传 SSH/Telnet。按 [xterm2 5.5.0 的修复](https://pub.dev/packages/xterm2/changelog#550---2026-11-20) 最小移植，移除默认读取回调。手动复制、手动粘贴、远端主动复制到剪贴板和已有输入法兼容行为保留；聚焦、重建视图、分片输入和用户手动粘贴均有回归。
2. **同步文件指定无上限 PBKDF2 工作量**：在派生密钥前验证工作因子、salt/IV 长度及截断数据。读取上限 2,000,000 次是本客户端的资源策略，并非协议官方上限；当前桌面和手机正常写入仍为 600,000 次。未来更高工作因子会明确拒绝，需评估后升级客户端支持。
3. **同步响应先全部读入才限长**：改为流式计数并在超限时取消读取，不信任 Content-Length。WebDAV、Gist 和 S3 均覆盖；Gist 元数据仍保留独立的 64 MB 上限，普通保险库默认 32 MB。
4. **SFTP 伪造文件名**：列表及递归传输入口拒绝空名、`.`、`..`、NUL 和路径分隔符，防止把远端“名字”解释成目标路径。Android SAF 原本已有授权根边界，本修复同时减少授权根内路径混淆。
5. **构建下载完整性**：将旧的 Gradle 2.10 wrapper 更新到经官方 SHA-256 核验的 9.1.0 wrapper，并固定 9.1.0 分发 ZIP 的 SHA-256。

## 同步与命令分组

用户已确认，现场“成功但无内容”的原因是 WebDAV 配置到了空目录；修正目录后原版即可同步。因此这里不将该现象归因于解密或保存故障。

新增保护：云端不存在保险库且本机也为空时，明确提示检查目录，不创建空文件并笼统提示成功；有本地资料的首次上传仍可用。同步结果显示云端读取和本机现有的主机、脚本及密钥数量。

兼容本机桌面 Netcatty 1.1.90 的 `monitorPanels` 和 `browserBookmarks` 集合，包括因果合并、删除、比较及缩量保护。用该桌面版本的代码生成合成加密样本，验证 WebDAV 读取、UI 状态、保存和重新打开后的恢复。

命令分组读取桌面已有的 `snippet.package` 与 `snippetPackages` 字段，显示折叠分组和未分组条目；编辑保持相同字段以便同步。

## 仍需知晓的边界

- AI 是用户主动配置和发送的功能。若自行开启终端上下文，会把相关内容发给选定服务商；自定义 HTTP 端点也会降低传输保护。没有发现默认把终端全文发给作者的行为。
- 明文 JSON 导出包含凭据；原界面已有提示。标准主机密码、私钥和同步密码存放于系统安全存储；这不保护已被攻破的手机进程。
- 仓库允许缺少正式密钥时使用调试签名；静态核验的官方 v1.9.3 APK 证书名称也为 Android Debug。这不等于 APK 开启调试，但应为自有发布保留稳定私有签名密钥。
- CI action 仍使用版本标签而非固定提交 SHA；尚未提供独立可复现构建证明。

本机提供的 APK 使用独立 `app.netcatty.mobile.audit` 应用标识，应用显示名称为“Netcatty”，并限制为 ARM64 架构，以便与已装版本并存。它是本机测试签名的 release 构建，不能当作原版的签名兼容升级包。源码保留原应用标识及通用架构配置，后续正式发布需使用自己的稳定签名。

具体测试结果、构建摘要和第三方 APK 静态核验记录见随交付的审查报告及构建清单。
